# 公众号合作媒体包 · 一页模板

> 填真实数据，不要把最高阅读冒充平均；没有历史商单也可以用真实公益/教程作品展示。

**账号定位**：【账号名称】，服务【细分人群】，帮助其完成【3类具体任务】。

**统计窗口**：【起止日期】；粉丝【真实值】；发布【篇数】；自然阅读中位数【真实值】；阅读区间【真实值】；是否包含付费加热【是/否】；数据采集日【日期】。

**代表文章**：①【链接+读者任务+本人贡献】；②【链接】；③【链接】。

**能交付什么**：可实测的功能/内容形式、账号和平台、素材类型、通常制作周期、什么不能做。

**合作流程**：Brief → 测试 → 框架确认 → 初稿 → 一次集中反馈 → 人工审核和发布 → 验收数据 → 回款。具体轮次以合同为准。

**广告披露**：商单依法按平台规则公示广告/合作属性；不保证自然推荐和特定转化。

**联系方式**：【官方公开商务邮箱/账号】，有效时间【日期】；如由媒介代理说明其角色和权限。
