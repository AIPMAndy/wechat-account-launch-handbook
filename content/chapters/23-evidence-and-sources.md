# 23｜证据与来源方法：怎样做到可核验，而不是假装「100%」

> **本章交付物**：证据等级、检索日期、主张对应来源、定期复核机制。任何公开调研都受资料可得性与平台变化限制，不可能穷尽 100% 的结果。

## 研究范围与时间

2026-11-15 对两条用户指定 X 长文、腾讯广告变现公告、微信推荐与 AI 内容治理、国家市场监管总局广告规则进行了交叉核对；并检查作者 GitHub 已有相关仓库避免与写作 Skill、排版工具重复。对市场单价、实际商单成交率、各个账号内部曝光池、合作回款流水未能独立核实，**明确保留不确定性**。

## 来源分级

- **A 官方法规/平台公告**：适合确认法律与公开规则，但要注明适用范围和更新时间。
- **B 媒体转述官方答复**：可判断平台口径，尽可能溯源原文；不能扩展成算法技术细节。
- **C 创作者一手自述**：可研究流程、工作分工、个人体验，但收入、转化等无法自动独立核实。
- **D 匿名经验/模型生成建议**：只作为待验证假设，不作为对外宣传结论。

## 更正协议

收到规则冲突时：保留旧主张与来源 → 搜索最新官方页面/后台 → 将结论更新成带日期版本 → 更新网站和 PDF → 在 `CHANGELOG.md` 记录变化。无法确认时标记「待核实」，不默默写成权威规则。

## 本项目的边界

不提供代发脚本、不提供刷粉、洗稿、水印移除或绕过平台审查的方法；不保证爆款、月收入、接单价格、推荐量、排名；不把第三方案例冒充作者本人。全文教程以可复现的行动和判断为主要产品，而不是利用他人文章作为免费转载库。
