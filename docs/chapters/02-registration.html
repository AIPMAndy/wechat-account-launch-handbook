WECHAT GROWTH HANDBOOK · 03/24

02｜注册、主体选择与安全配置：从零逐项操作

本章交付物：可发布账号、正确主体类型、可信主页、安全权限检查表。菜单名随版本可能变化，按平台实时提示为准。

2.1 账号类型先选对

腾讯官方将公众号分为 订阅号 和 服务号：订阅号面向信息传播，适合主要发布内容的个人/媒体；服务号偏企业与组织服务能力。类型与主体相关的功能、群发限额、认证资格和可使用的 API 都可能不同。不要因为听到“企业号权重更高”就去选服务号；没有公开证据能证明这种泛化说法。

操作：打开官方 https://mp.weixin.qq.com/ →「立即注册」→ 查看订阅号/服务号适用条件 → 选择与你本人/企业材料一致的主体 → 验证邮箱/身份/主体 → 按指引设置名称、头像、简介。请勿使用第三方代办链接，也不要给陌生人短信验证码、扫码登录或管理员权限。

2.2 主体选择清单

检查点 个人起号 企业起号
主体资料 本人实名信息 营业执照、法人或授权资料
品牌命名 明确所属垂直领域 与商号/商标/合法使用权一致
认证和功能 具体以后台资格为准 费用、材料、权限需核验
运营安全 本人管理，备份恢复方式 主负责人 + 最小化成员权限
变现和结算 核对个人适用能力 公司财务、合同、发票与纳税流程

注册限制、可改名次数、认证费、业务类型随平台与主体变化，不写死从第三方站点抄来的具体数字。遇到冲突，以注册界面/腾讯客服/微信公众平台公告最新结果为准。

2.3 账号首页四件套

名称：能让陌生人知道领域与主体即可；简短好记，避免未经授权使用机构名或职业资质。头像：手机缩略尺寸仍能识别，避免低质量 AI 虚拟人引发身份误解。简介：你服务谁、具体解决什么、有什么可信依据。介绍/菜单：主页代表作、免费入门资料、合作方式三者优先，不用做复杂导航。

示例（教学模拟）：

名称：小林讲 AI 办公
简介：每周实测一个 AI 办公场景，写给想少加班的运营新人。每篇附实际步骤、失效情况和可复制模板。
关注后回复：入门｜查看公开资料导航（不要求转发、付费或关注其他账号）

2.4 安全审计 SOP

  1. 确认账号归属、管理员微信、绑定邮箱与恢复路径；资料保存在公司正式台账。
  2. 运营人员尽量使用可撤销的官方成员/运营权限，不共享主号登录；离岗当天撤销权限并检查设备登录。
  3. 不把授权 cookie、登录二维码、API 密钥交给非官方发布脚本；任何第三方排版工具先评估权限。
  4. 发布前开启必要审核。涉及医药、投资、法律、招聘承诺等高风险行业，额外人工复核资质与事实。
  5. 留存文章源文件、引用链接、图片授权和修改记录，便于申诉、纠错与长期归档。

2.5 发布模式差异

平台的「发表」「群发通知」等控件已有过调整。发表但关闭群发通知与通知全部粉丝在可达性和次数上不完全相同。常见口径是订阅号每天一次群发通知、服务号每月四次，但发布前必须看当前账号界面的配额提示。不要承诺“关闭通知能无限拿推荐”；微信已表示关闭通知本身不会影响符合规范的内容获得推荐。

验收：你能独立登录、保存草稿、设置作者/摘要/封面、预览到手机、发出测试文章并查询统计界面。
